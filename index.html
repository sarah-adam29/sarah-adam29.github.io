Solar project finance: what Gulf solar tariffs imply

KSA and UAE solar tenders have set some of the lowest tariffs in the world. I built an annual project finance model (LCOE, project and equity IRR, DSCR) from cited public assumptions, and checked it against an Excel answer key built by hand.

View the repository Web calculator: coming soon

Headline finding

~3%

cost of capital implied by awarded tariffs (KSA 3.3%, UAE 2.8%), against 7.5–7.7% in published WACC estimates.

How I work

Start from the decision

Every model answers a question someone actually has to decide.

Source it or label it

Each assumption cites a public source or is marked as judgment.

AI-built code is tested against a model I build independently by hand.

Public data only
